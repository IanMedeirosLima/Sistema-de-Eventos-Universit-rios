Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Web, focado no desenvolvimento **front-end** utilizando apenas **HTML5 e CSS3 puros**, com design responsivo e código semântico.

---

## 📌 Sobre o Projeto

O objetivo do projeto é criar um portal web para divulgação e gestão visual de eventos acadêmicos de uma universidade, como palestras, minicursos, workshops e oficinas. O site foi projetado para oferecer uma excelente experiência de navegação tanto em computadores quanto em dispositivos móveis, sem o uso de frameworks externos ou JavaScript.

---

## 🚀 Estrutura do Site

O projeto é composto por 3 páginas principais:

### 1. 🏠 Página Inicial (`index.html`)
* **Navbar:** Menu de navegação entre todas as páginas.
* **Apresentação:** Seção introdutória da instituição de ensino e portal de eventos.
* **Cards de Eventos:** Exibição de 6 eventos organizados em layout *grid/card* utilizando **Flexbox**. Cada card contém:
  * Imagem ilustrativa
  * Nome do evento
  * Categoria (Palestra, Workshop, Minicurso, etc.)
  * Data, horário e local
  * Breve descrição do evento

### 2. 📅 Programação (`programacao.html`)
* Apresentação da cronologia geral dos eventos através de uma **tabela estilizada e responsiva**.
* Utilização técnica avançada de `rowspan` e `colspan` para mesclar células de horários e dias da semana.
* Informações de data, horário, evento, categoria e local.

### 3. 📝 Inscrição (`inscricao.html`)
* Formularização para simulação de inscrição de estudantes em um evento acadêmico.
* Campos do formulário:
  * Nome completo
  * E-mail
  * Curso e Período
  * Seleção do evento desejado
  * Modalidade (Presencial ou Online)
  * Confirmação dos dados
  * Botão de envio/inscrição

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias fundamentais da web sem bibliotecas ou frameworks externos:

- **HTML5 Semântico:** Uso correto de tags como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<table>` e `<form>`.
- **CSS3 Externo:**
  - Estilização completa e identidade visual própria.
  - Layout dinâmico com **Flexbox**.
  - Responsividade para dispositivos móveis utilizando **Media Queries**.
  - Seletores CSS, classes e IDs otimizados.
